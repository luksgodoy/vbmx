# VbMx — versão de teste

Mixer profissional que roda no navegador, sem instalar nada. Abra o `index.html` publicado
(ou sirva a pasta com qualquer servidor estático).

- **Stems pelo plugin Sidra**: separa a faixa no próprio aparelho (htdemucs). Precisa de Chrome ou Edge; na primeira vez baixa ~90 MB.
- **Precisa de internet para a análise**: o BPM e o tom vêm do Essentia (carregado por CDN).
- **As músicas ficam no aparelho**: nada é enviado.
- **Pasta "294 Records"**: 5 faixas da 294 Records já vêm na biblioteca (MP3 em `faixas-294/`, públicas e baixáveis); é só arrastar para um deck.
