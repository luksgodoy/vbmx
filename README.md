# VbMx — versão de teste

Versão de teste do VbMx: roda no navegador, sem instalar nada. Abra `index.html` publicado
(ou sirva a pasta com qualquer servidor estático).

- **Stems no navegador**: plugin Sidra (htdemucs, MIT) separa a faixa no próprio aparelho, sem enviar nada. Precisa de Chrome/Edge (WebGPU) para ser rápido; na primeira vez baixa ~90 MB.
- **Precisa de internet para a análise**: o BPM e o tom vêm do Essentia (carregado por CDN).
- No iPad (Safari), use **Adicionar faixas** e escolha as músicas pelo app Arquivos. As músicas ficam no aparelho; nada é enviado.
